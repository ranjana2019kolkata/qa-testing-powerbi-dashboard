# QA Testing & Quality Assurance — Power BI Dashboard

A 7-page Power BI portfolio project analyzing test execution and defect
management data for a simulated IT Testing & QA environment, built on a
proper star-schema data model.

## What's included
- `QA Testing & Quality Assurance Dashboard.pbix` — the full interactive Power BI file
- Case study PDF — design decisions, DAX highlights, and a debugging
  write-up covering a real data quality fix and Power BI modeling issues
- Dashboard screenshots

## How to explore it
Download `QA Testing & Quality Assurance Dashboard.pbix` and open it in Power BI Desktop (free) —
slicers, page navigation, and all visuals are fully interactive.

## Highlights
- 9 dimension tables, 2 fact tables, 15 relationships
- 25+ DAX measures, including cumulative time-intelligence patterns and
  a cross-fact-table relationship using USERELATIONSHIP()
- Found and corrected a real logic flaw in SLA breach tracking, fixed
  in Power Query
